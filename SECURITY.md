# Security policy

odin-db handles database credentials, so security reports are a priority.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through GitHub: **Security → Report a vulnerability** on this repository.

Include affected versions, steps to reproduce, and impact. You will get an acknowledgement within 7 days. Once a fix is released, the advisory is published with credit unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
